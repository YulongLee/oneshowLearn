# 收藏来源联动补齐（2026-10-05）

## 范围

在现有标题、面包屑或操作区增加次级收藏按钮，不新增大模块：课程、课时、课件、课时配套资料、实战项目、课程/项目笔记。资源中心继续使用已有资源收藏，个人笔记继续使用原星标；所有入口汇总到“我的收藏”。

收藏与取消收藏双向同步。收藏课时回到对应课时，收藏课件打开原预览，收藏资料定位到原课时的具体资料，收藏课时笔记打开本人原笔记；项目收藏不启动项目。取消收藏不删除原内容。

## 数据与权限

- 沿用私有 workspace JSON，新增可选 contentFavorites 类型化引用，无数据库迁移。
- 不混用课程资料 content_library 与资源中心 content_items 的数字 ID；资料引用绑定 placementId。
- 新增 GET /me/favorites/contents，仅解析当前账号的引用，不返回其他账号笔记或私有资料正文。
- 写入沿用版本冲突保护；显式写入新引用需要当前版本。旧客户端未提交新字段时保留已有引用。
- 收藏不提升课程/项目访问权限。权限撤销、内容下架或笔记进入回收站时保留收藏引用并如实显示状态；被锁定资料不泄露私有标题。
- 不复制内容、签名下载地址或私有笔记正文到收藏状态，不创建项目学习记录、订单或权益。
