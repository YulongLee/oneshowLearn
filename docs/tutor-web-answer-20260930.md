# AI 导师联网回答 — 2026-09-30

更新：用户随后明确要求部署，本功能与按钮优化已上线，详见 `tutor-web-release-20260930.md`。以下为开发阶段记录。

## 范围

本地开发和自测，尚未部署。AI 导师在「通用建议」输入框下提供可选的「联网回答」按钮。默认不开启；关闭后恢复普通建议，课程资料问答继续使用现有按权限检索逻辑。

联网回答使用后台已经配置的阿里云密钥和模型，不更换供应商或模型，不增加前端凭据。当前原生文字联网协议接入 DeepSeek V4 Flash/Pro、V3.2 及 Qwen Plus/Max/Flash/Turbo 系列；不在已接入名单中的模型显示不可用，不能把普通补全当作联网成功。

## 接口与依据

- 阿里云官方说明：<https://help.aliyun.com/zh/model-studio/web-search>。
- 使用既有可信域名下 `/api/v1/services/aigc/text-generation/generation`，由服务端从已经验证的配置推导；不接受客户端接口地址。
- `enable_search: true`，`forced_search: true`，`enable_source: true`，`enable_citation: true`，`citation_format: "[ref_<number>]"`。
- 原有 Chat Completions 普通问答不变。原生接口用于获取真实的 `output.search_info.search_results`，而非从模型正文猜测链接。
- 当前 `deepseek-v4-flash` 已真实调用验证：返回搜索来源、来源编号和实际 Token 用量。

## 权限与隐私

- 请求仅含用户本次问题及同一会话、同一联网模式下最近最多 4 轮记录。
- 不把课程检索结果、私人学习笔记或产品简介自动发给联网搜索。带课程 ID / 产品上下文的联网请求直接拒绝；切换模式时不继承其他模式的历史。
- 网页和历史中的指令视为不可信数据。来源链接仅允许公开 HTTP(S) 域名，拒绝凭据 URL、IP/本地地址、不支持协议和非默认端口。应用不抓取用户指定的任意地址，不发送密钥到网页域名。
- 回答必须包含可与服务商返回来源对应的引用；无来源、伪造编号、无效链接、超时及调用失败均明确报错，不退回普通答案冒充联网。

## 保存与后台

- 复用私有会话表及幂等请求，不新增数据库表。`mode=web` 与回答、来源、检索时间一同保存，切页/刷新恢复。
- 网页来源单独标记，不误走课程权限校验；课程旧记录仍执行原有当前权限校验。
- `/admin/ai` 新增「导师联网回答」开关；总开关、导师开关、联网开关均会在服务端拦截新调用。
- 旧配置缺少 `web` 字段时补全默认值；实际可用仍要求 AI 启用且配置为已接入模型。联网调用计入现有每账号、全站、频率及并发限制。
- 调用记录标记功能 `web`，保存真实输入/输出 Token；搜索可能额外收费，平台不将 Token 数当成完整费用账单。
- 旧 `/learning/ai/tutor` 无状态接口仍只接受原来的两种模式，联网功能通过私有会话接口提供，避免接收客户端伪造的联网历史。

## 验证

构建及全套测试 167 项通过（78 项前端/模型、85 项 API、4 项 Sites）。新增验证包括原生参数/来源解析、无来源与伪造引用拒绝、不支持模型/上游异常/超时、私人上下文隔离、联网历史保存及账号隔离、后台开关与用量记录、旧配置兼容。

真实浏览器在隔离本地账号中实测「通用建议 → 联网回答 → 发送」：成功返回带 4 处网页来源的回答，来源卡片显示原文链接与检索时间；切到资源中心再返回，联网模式、问题、回答与来源完整恢复。390px 小屏无横向溢出，联网按钮与发送区可见。

生产尚未更新；下一次发布需同步前后端，包括新 `server/ai-web-search.mjs` 及修改过的 provider/configuration/service/conversations 文件，不能仅发布前端。原发布脚本的严格文件比较会阻止遗漏后台的发布，需在明确部署请求后扩展发布范围并备份验证。不要上传本地测试会话。
