# 官方学习社区（本地开发）

## 范围

按照 `codex-clipboard-474e169f-6ebc-44db-a642-3abbd989a3bb.png` 的内容广场结构重做 `/community`，保留全站共享导航。微信群入口按用户明确的文字放在内容区左上；右侧保留会员群介绍卡。横幅沿用现有社区插画，没有使用参考图的二维码或复制示例文章。

后台入口 `/admin/community`：管理员和编辑可维护独立官方文章，设置分类、专题、封面、摘要、Markdown 正文、置顶和推荐；草稿预览、明确发布、归档恢复、发布历史载入，所有变更检查版本，记录内容审计。草稿与发布快照独立，编辑已发布文章不会直接改动线上版本。

社区设置维护广场文案、真实二维码地址、入群开关和展示对象，以及最多八个推荐资料引用。默认只向持有有效课程权益的账号返回二维码，可明确选择所有登录用户。未配置/过期权益不返回二维码地址。二维码本身的微信审核与有效期由运营维护；已经获得图片的用户可自行转发，本站权限不能替代微信群审核。

资料推荐只返回已发布来源元数据，复用 ResourceReader 的原始权限校验，不公开付费正文或附件。官方文章向登录用户开放，不自动导入课程资料或私人笔记。旧“社区草稿”仍在学习笔记中，未删除。

## 使用与后续

1. 本地后台“官方社区内容”新建文章，保存草稿 → 预览 → 确认发布。
2. “页面与会员群设置”配置真实二维码图片地址、展示范围和推荐资料，再保存并发布。
3. 用户社区无硬编码示例文章；尚未发布文章时显示待发布状态，不虚构浏览量、点赞量、会员人数。
4. 部署需包含新的 `server/community-definition.mjs`、`server/community-routes.mjs`、API 挂载和前端产物，不是纯前端发布。当前请求仅本地开发，未部署。未来发布先备份数据库，启动时只新增 `community_records` / `community_history` 两表及索引，不导入本地测试记录。
