# 购买入口导航修正（本地）

用户要求从平台内点击“解锁完整课程”后保留左侧菜单。此前 `/membership` 在顶层直接呈现独立销售页，绕过了持久化的 WorkspaceShell。

## 修改范围

- `/membership` 与 `/membership/` 接回现有 LearnerWorkspace，复用侧栏、搜索、账号及移动抽屉，不创建第二个 Shell。
- CourseOffer 增加嵌入模式：只呈现面包屑和销售内容，不重复顶部营销导航，不嵌套 main 地标。
- `/course-offer` 保留独立官网销售形式，复用同一个 CourseOffer 与 CourseCheckout，不复制商品、课程或支付逻辑。
- 嵌入布局按可用空间切换介绍/价格双栏或上下排列，保留已有字号、素材、价格和付款状态。
- 没有修改后端、价格配置或生产数据。未部署。
