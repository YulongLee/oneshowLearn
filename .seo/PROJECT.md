# OneShowLearn SEO / GEO 项目

- 审计目标：https://oneshowlearn.com/；中文、以中国 PC 端课程购买和学习为核心。
- 产品：AI OPC 课程与学习平台，一次购买解锁当前完整课程及已发布实战项目；微信/支付宝支付、课程权限和私人学习记录保持原逻辑。
- 品牌：OneShowLearn，OneShowAiLab 出品；讲师花名 Cody老师，简介使用拥有者已经提供的内容。
- 本轮范围：全站公开页技术 SEO、可抓取内容、结构化实体、GEO 可读性、公共链接及自测。本轮未授权 Git 提交、线上发布、搜索平台提交、CMS 写入、统计/解析/证书激活或外部宣传。
- 基准来源：公开 GET/HEAD、线上原始 HTML 与渲染页面、源码、技能脚本、官方文档。私人课程全文、账号/订单/笔记/聊天/管理数据不得进入 SEO HTML、sitemap、llms 或报告。
- 数据原则：流量、排名、转化、收录、真实用户 CWV 仅使用已连接第一方数据；不可用即 unknown/null。不虚构评价、收入、完课率、权威认证或品牌 sameAs。
