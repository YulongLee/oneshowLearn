# AI 导师回答渲染与引用修正发布

用户授权开发、自测后上线。2026-09-30 已发布 https://oneshowlearn.com/tutor。

## 实现

- 专用 `TutorAnswer` 使用 react-markdown / remark-gfm，支持标题、段落与换行、嵌套列表、表格、行内代码、代码块与复制。仅作用于 AI 对话，不替换个人笔记编辑器。
- 正文中已知 W/S 引用变为带无障碍名称的来源链接；未知编号保持原文，不伪造链接；代码与已有链接内部不做引用替换。
- 不执行 HTML，不加载 Markdown 图片，不允许危险协议或本地地址链接。原始回答仍用于复制和保存。
- 来源默认折叠；展开先显示三条，其余由用户展开；区域有最大高度，网页来源显示域名而非伪装成正文摘录。
- 模型身份问题直接读后台实际模型配置，记录 `system-model` 类型与回答时间，不调用模型、不计模型用量，不编造网页来源。
- 增加明显无依据引用校验：独立堆叠编号或正文承认引用只是凑格式、没有参考网页时拒绝。提示词要求引用紧跟其支持的事实。
- 同样规则应用于旧联网回答读取：不展示明显错误的原回答，允许重新提问，不删除或改写数据库原始记录。
- 该规则不等同于对任意网页和事实的完整语义校验；仍提示核对原文。
