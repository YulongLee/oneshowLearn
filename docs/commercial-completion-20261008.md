## 后台操作

三个新增后台入口仅站点所有者可操作；内容编辑员、学员和匿名用户不能调用对应管理接口。

### 经营与体验监测 `/admin/analytics`

经营漏斗使用服务端同一注册批次的注册、下单、核验付款、付款后学习活动，不接受客户端声明付款成功。收款总额、人工核实登记退款分别按记录时间展示，不替代支付平台结算对账。

体验统计默认关闭，可在后台开启。浏览事件只保存页面分类、临时页面会话、异常类型和有限性能指标；不保存账号标识、IP、完整 URL、搜索内容、消息、笔记或错误堆栈。刷新会话重新计数，不作为独立访客人数。遵守 Do Not Track，数据保留 90 天，每 15 分钟清理至最新 20 万条；达到清理周期前可能短暂超过条数上限。

性能数据按最初完整加载页面归属，SPA 切换另记浏览事件。P75 使用最近最多 5 万条样本；INP 为浏览器事件时长采样近似值，不声称已完成标准 Web Vitals 实现。前端采集为尽力而为，失败不阻断业务操作。入口有批次大小、类型、值域、同会话指标去重和请求限流；公开统计仍可能受非真实浏览请求干扰。

### 资料自动解析 `/admin/parsing`

1. 在服务器私有环境配置 `MINERU_API_KEY`，不要放进前端、Git 或公开日志。依照现有环境更新流程使服务读取密钥。
2. 后台开启资料解析；在附件库上传私有 PDF、PPTX、DOCX 或图片。
3. 选择附件，确认允许传给 MinerU，再提交。
4. 查询原任务，审核返回的 Markdown；确认公式、表格、引用、权限和私人信息。
5. 导入为新的资料库**草稿**，再用现有资料库/课时管理关联并发布。不会自动覆盖旧资料、关联课时或发布。

官方接口协议参考：[MinerU 文档](https://mineru.net/doc/docs/index_en/)。本适配器采用上传文件批次接口，当前支持应用已有上传类型，文件上限 200 MB / 600 页。视频、音频不在文档解析范围，需提供字幕或文稿。只导入压缩结果中的 `full.md` 文字，不导入图片或执行内容；压缩包、解压正文、JSON 和草稿正文均有读取上限。长文需人工整理或分段后导入。

提交和上传发生超时，任务保留为“待核验”，不自动重新提交以免重复消耗额度。无远端编号时先到 MinerU 后台核对原任务；关闭本地任务不会取消远端任务。后台每分钟最多查询两个任务；不自动重传附件，也不对待核验提交自动重试。关闭任务保留原附件和记录。审核导入与关闭使用版本检查，防止覆盖并发操作。

外部地址仅允许已核对的 MinerU 上传/结果主机，要求 HTTPS，拒绝重定向及解析到内网的地址。若服务商以后更换主机，需要核对官方协议后明确更新允许列表，不应取消地址限制。

初次开发使用隔离模拟服务。随后业主提供 Token 并授权真实联调：1 页、802 字节的无私人信息测试 PDF 成功提交、上传、查询与读取 Markdown，约 23 秒完成，正文 179 字符，测试标记准确匹配。仅该次真实测试消耗服务端解析额度，没有上传真实课程资料或改动线上配置，Token 未写入测试文件或代码。

### 课程结业证书 `/admin/certificates`

1. 全部正式课时发布，包含实际教学附件、课件文字或已发布关联资料；不能使用演示素材或空课时启用。
2. 填写完整课时数量（当前完整课程应为 40），确认发证目录并启用。
3. 学员具有有效课程权益，并在服务端记录完成全部当前正式课时后，自动颁发 OneShowLearn 课程结业证书。
4. 学员在“我的成果”查看并下载；站内通知链接到成果页面。下载文件为独立 HTML，可在浏览器打印或保存 PDF。
5. 后台查看颁发记录；撤销需填写原因，保留原记录和学员可见原因，不自动重新颁发。

证书固定颁发时姓名、课程名、目录版本、日期与唯一编号。同一账号/课程只颁发一份。旧学习完成记录不自动猜测或补写版本凭据；本功能上线后的正式完课操作记录凭据。课时或关联资料变化会暂停新证书，需管理员确认新目录，学员补齐当前版本完成记录。已有证书保留颁发时目录。

自动颁发基于课程完课记录，不新增考试、实名身份审核、外部认证、公开验真页面或密码学签章；不能用证书表达未实现的能力评测。后台启用后已有有效完课凭据可由定期任务补发；任务按批次处理，不承诺立即处理全站历史账号。撤销课程权益后不能继续下载证书。
