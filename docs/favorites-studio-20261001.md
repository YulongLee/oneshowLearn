# 收藏页设计与验收（本地）

## 范围

- `/favorites` 改为统一内容资料库：页面标题、私人可见提示、分类数量、站内收藏搜索、标签筛选、排序、卡片／列表视图。
- 移除旧版统计、最近收藏和推广右栏，优先保证内容与文字阅读宽度。
- 共用菜单、账号、课程访问权限与版本化个人状态接口保持不变。
- 原有课程、资源与星标个人笔记仍使用账号真实记录；不新增展示用收藏。
- 优先使用课程 CMS 封面，通用插画标明“分类示意”；笔记用文本摘要。
- 取消收藏须确认，只移除收藏关系，不删除笔记或原内容。
- 保留无法读取的资源收藏关系并提示加载失败／不可用；缺失的历史时间不伪造。

## 验证

- `npm run build` 成功。已有主包大小警告仍存在，不影响构建。
- `npm test`：213 项通过（103 前端／模型、106 API、4 Sites）。
- 新增 5 项收藏模型测试，覆盖去重、私有笔记回收站隔离、加载／不可用状态、组合搜索与排序、只取消目标收藏、旧记录兼容。
- 浏览器使用本地隔离预览管理员账号的既有功能测试笔记，验证：加入收藏、导航回收藏页、刷新保留、网格／列表切换并记忆、搜索无结果与重置、阅读弹窗、取消操作时保留、确认取消后归零。测试结束取消新增星标；笔记正文保留。
- 320、390、768、1024、1440、1920、2560px 检查；页面无横向溢出，卡片随内容宽度呈 1／2／3／4 列，标题 18px、摘要 14px；手机列表堆叠。
- 本地资源目录目前为空，资源分类与权限状态使用模型测试覆盖，没有声称完成生产资源的浏览器端验收。
