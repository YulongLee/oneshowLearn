# 学习路线图与 AI OPC 课程职责分离

日期：2026-09-28。仅本地开发，未部署、未修改生产数据。

## 实现

- `/paths` 展示五阶段目标、产出、真实整体进度和下一步建议，不再重复课程列表、项目推荐、日历、任务或导师。
- 阶段按钮进入 `/opc/phase/1` 至 `/opc/phase/5`；保留按需展开的已发布学习方向目录。
- `/opc` 聚焦章节、配套资料、继续学习和阶段成果，使用紧凑阶段切换；导师为默认折叠的预览。
- 未指定阶段时根据实际课程进度选择，显式阶段链接优先。菜单统一为“AI OPC 课程”“学习路线图”。
- 两页共用现有 CMS 课程与账号进度；未生成内容、修改阶段映射或新增学员记录。
