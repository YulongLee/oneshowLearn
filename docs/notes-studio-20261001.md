# 学习笔记双栏工作空间

用户要求提升 `/notes` 的商业化视觉与使用体验。先完成本地开发和验证，随后经用户“上线吧”明确授权发布；本次未提交或推送 Git。

## 设计与边界

- 保持共享菜单与账号栏不变；移除页面内重复统计、宣传海报及未开放功能卡。
- 简洁标题、来源切换和统一操作栏，下方使用一体化笔记列表/文档双栏。
- 列表支持全文搜索、标题/更新时间排序、标签和收藏筛选、回收站；正文使用约 16px 阅读文字、有界行宽、清晰标题与元数据。
- 个人笔记保留 Markdown 导入/导出、格式快捷操作、任务勾选；增加编辑预览和专注阅读，保存按钮持续可达，支持 Ctrl/⌘ S。
- 课程/项目笔记复用富文本编辑器，保留视频时间、来源链接、版本校验及恢复；统一列表和阅读外观，并使用页内未保存确认。
- 内容宽度不超过 800px 时采用列表/详情切换，保留返回列表和编辑草稿，避免双栏挤压。
- 个人笔记仍明确为手动保存，不宣称自动保存或已接通独立笔记 AI。原账号状态与课时笔记接口不变，无生产数据操作。
