## 前一轮实现记录

本次为本地开发，未部署，未发送真实短信，未使用真实微信身份联调。

## 入口

- 用户登录 `/login`：邮箱登录 / 验证码登录 / 微信扫码。嵌入购买流程的登录卡复用相同组件与成功回调。
- 已有账号 `/account` → 登录方式：绑定手机号或微信，不改变账号 ID、订单、权益和笔记。
- 管理员 `/admin/login-settings`：短信签名、模板、发送上限、AccessKey，微信网站应用 AppID / AppSecret。仅 admin 可读写；editor 无权访问。
- 管理入口 `/admin/login` 保持邮箱密码，不根据用户角色自动跳转平台。

## 启用前准备

1. 服务器设置 `APP_URL=https://oneshowlearn.com`（与用户实际访问的规范域名一致）和 `AUTH_CONFIG_ENCRYPTION_KEY`（32 字节随机值的 64 位十六进制）。加密主密钥单独备份，绝不可提交 Git 或放在前端环境变量中。
2. 阿里云开通短信服务；提供审核通过的签名、验证码模板（变量 `${code}`、有效期 5 分钟）及仅允许 SendSms 的 RAM AccessKey。AI 模型 API Key 不能用于短信。建议同时配置云平台的发送频控、费用告警和防刷措施。
3. 微信开放平台申请并审核网站应用、微信登录权限。需要网站应用 AppID / AppSecret，不是公众号、小程序或支付商户配置。回调地址由服务器决定：`https://oneshowlearn.com/api/auth/wechat/callback`；开放平台填写对应的授权回调域名。
4. 在管理页填好参数后启用需要的通道；保存不等于服务商验证成功。使用自己的真实手机号、微信完成一次登录与已有账号绑定联调，再开放使用。网站弹出扫码窗口，需允许弹出窗口；Windows/Mac 微信可能按官方行为优先显示快速确认，仍可选择二维码。
5. 为防止产生独立账号，已有邮箱用户先邮箱登录再绑定。新用户明确勾选创建账号才能自动注册；全站关闭注册时不能创建新账号。

## 安全与数据

- 新 `login_identities` 将已验证手机号 / AppID 范围内 OpenID 绑定到原 users ID。唯一约束阻止跨账号覆盖以及同一账号重复绑定；不根据昵称、手机号猜测、未验证邮箱或 UnionID 自动合并账号。
- 外部登录新用户 `email=NULL`、`email_verified=0`、空密码哈希（不可密码登录），非伪造邮箱。授权、私有附件下载、AI 生成后的会话复查都承认已验证登录身份，同时检查停用状态与 token_version。
- 老数据库升级会先创建权限 0600 的完整 SQLite 快照 `*.before-login-*.bak`，再事务内重建 users 的可空 email 约束，保留所有列、ID、自增序列、索引及触发器，检查外键。其他内容表不重写；新库直接使用可空 email。
- 验证码仅存 HMAC：5 分钟、最多 5 次错误、60 秒重发、旧码作废、一次消费；每手机号每日 5 次、每 IP 每小时 10 次，全站默认每 24 小时窗口最多 100 次（包括失败/超时尝试）。限额持久化，重启不会归零；超时不会自动重复发送。大规模开放前应结合平台风控评估额外人机验证。
- 绑定时，邮箱密码账号验证当前密码；无密码账号必须在原身份登录后 10 分钟内绑定。绑定验证码/授权关联用户和 token_version，别的账号不可消费。该版本不提供自动换绑、解绑或账号合并，避免丢失唯一登录方式。
- 微信 state 随机、限时、一次认领，额外绑定 HttpOnly + SameSite=Lax Cookie，生产使用 Secure；轮询使用独立随机凭据。授权码在服务器兑换；不向前端返回微信 access_token / refresh_token，不将本站 JWT 放在 URL。取消、过期、错误、禁用/轮换配置均失败关闭。
- 密钥使用独立 AES-256-GCM 加密；本地测试密钥文件 `.auth-config.key` 为 0600，生产必须用环境主密钥。管理页仅返回是否配置，空白保留、显式清除；If-Match 防旧配置覆盖。已绑定用户后禁止直接更换微信 AppID。
- 过期临时挑战按请求触发清理（超过一天删除）；浏览器 Cookie 最多 10 分钟。数据库与备份仍包含身份关联，按私有账号数据保护。
