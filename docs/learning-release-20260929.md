# 课程学习与实战项目交付记录 · 2026-09-29

状态：本地开发与验收通过，已部署至既有腾讯云上海生产环境；正式 HTTPS 验证通过。

## 实现范围

- 课程、项目共享课时本体；分别编排到课程章节、项目阶段，分别保存个人进度、笔记、任务和权限。
- 学习页使用同一 WorkspaceShell：上下文课程目录、视频/课件、笔记三栏；手机目录抽屉与笔记底部面板。侧栏保留调整宽度、图标折叠、隐藏、键盘操作，拖动不再显示通栏紫色双边框或原生提示。
- 视频播放/暂停、原生音量/进度/全屏/字幕、倍速、断点恢复、定时保存、媒体链接续期；无视频的课时仍可图文学习。
- PPT 图片页、缩略图、上下页、全屏、原件下载；按后台时间映射自动跟随，手动翻页暂停跟随。
- 富文本笔记支持加粗/斜体/下划线/列表/链接/私有图片、视频/PPT 截图手绘标注、时间点及页面跳转、自动保存、版本冲突、回收站恢复，并接入学习笔记页。大编辑器按需加载。
- 图文、代码、Prompt、附件、操作步骤、预期成果与截图、实践清单；课程和项目课时可显式互相关联。
- 项目目录由 API 驱动：分类、技术栈/标题/简介/标签搜索、排序、分页、真实数量；详情、开始项目、恢复位置、Prompt 版本、阶段验收、成果记录。
- 逐阶段权限在后端检查；项目权益和关联课程权益分离。完成教程或勾选清单不代表平台验证产品已上线。
- 复用商品、订单、付款记录；扩展项目商品和独立项目权益。仅管理员可确认人工收款，内容编辑不可确认；重复确认不会重复授予。
- AI 服务抽象携带当前授权课时、章节/项目/阶段、文字稿、PPT 文本、用户笔记、当前 Prompt 与进度。默认未配置，界面明确不可用，不伪造回答。

## 管理操作

1. `/admin/content`：维护课程和章节；`/admin/projects`：维护独立项目介绍、发布状态和课程关联。
2. `/admin/library` 和 `/admin/assets`：维护源资料与附件。附件库新增独立多选上传，支持图片/视频/PPT/PDF/VTT 等；上传成功不自动发布。新课时引用源资料，不复制出独立正文。
3. `/admin/learning` → 共享课时：配置视频、VTT 字幕、PPT/PDF 原件、逐页图片/文字/时间映射、任务、操作步骤、成果、关联课时位置 ID。
4. 同页面 → 课程 / 项目编排：选择共享课时及目标章节/阶段、顺序、试看、正文/代码/Prompt/文字稿引用，显式发布。多个投放共用课时内容，但个人记录独立。
5. 项目分类、项目学习配置、项目阶段分别维护类别/收费方式/技术栈/难度/时长/验收清单。关联选项显示所属课程/项目及 ID，避免同名阶段混淆。
6. `/admin/opc` 保留显式章节到五阶段映射；已编排的新课时自动出现在对应映射中，不自动制造映射。
7. 已发布 Prompt 更新原资料后，需显式重新保存编排才升级锁定版本；旧版本保留。

## 数据变化

`server/learning-schema.mjs` 记录三次版本迁移，新增共享课时/投放/素材关系、项目类别/配置/阶段、私有进度/笔记/项目运行/验收、Prompt 历史及项目权益。

原 `products` 保留 ID 和所有既有列/值，增加项目关联并允许课程或项目二选一；原有订单关系保留。迁移不导入课程、阶段、学员、权益或示例资料。代码回退不能恢复旧数据库覆盖新用户记录。

主要新增前端：`AdminLearning.jsx`、`LessonWorkspace.jsx`、`ProjectsHub.jsx`、`LearningNotesLibrary.jsx`、`RichLessonNote*.jsx`、`learning-system.css`。主要服务端：`learning-schema/model/routes/commerce/note-body.mjs`、`course-ai-service.mjs`。复用并增量接入既有课程、资料、账户、OPC 和个人成果模块。

## 明确边界

- 真实 AI 模型尚未接入；本次交付服务抽象、上下文和禁用状态。没有在前端写入 API 密钥。
- 自动支付渠道尚未接入；复用现有人工确认流程，不会自动扣款。会员字段不等于已开通自动续费会员。
- PPT 在线页使用管理员上传的图片与原件，不在服务器自动执行 Office 转换；附件沿用现有上传大小限制。转码、CDN、DRM、语音转写和证书发行不在本次实现中。
- 生产不发布隔离测试素材/账号。管理员完成真实课时编排后，学员才会看到相应内容；旧课程资料入口继续可用。
- 没有自动把用户产品部署到其服务器、接入其商户支付或声称已获得真实用户；学习验收、作品上线与商业成功保持区分。
