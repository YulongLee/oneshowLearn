# AI OPC 学习空间

完成日期：2026-09-26。当前为本地开发版本，未部署到生产环境。

## 入口与范围

- 学习空间：/opc，工作台侧栏「AI OPC」进入。
- 课程编排：/admin/opc，仅管理员和编辑可访问。
- /app 仍是个人工作台，/ 仍是官网。

## 已实现

- 参考图的开发者横幅、五阶段路线、紧凑内容列表、阶段成果与右侧辅助栏。
- 从 CMS 读取已发布的文档、Prompt、代码、模板、任务、清单、短视频和资料。
- 点击资料打开阅读窗口；登录后记录开始状态，手动完成后保存进度。百分比按实际已完成项计算。
- 按当前账号保存产品信息、阶段、11 项里程碑和每阶段成果，多窗口保存冲突有版本检查。
- 导师问题可保存为学习笔记。实时 AI 问答、自动项目评审尚未接入，明确标为预览。
- 响应式布局：桌面三栏，窄屏辅助栏下移，平板和手机抽屉导航，手机首屏图文分区。

## 配置课程

1. 在「产品与路径」配置路径与项目包，项目包决定课程访问权限。
2. 在「AI OPC 编排」新建或选择章节，分配阶段；可编辑标题、简介、排序和发布状态。
3. 在「课程资料」为章节添加正文、视频、模板等，设置资料发布状态及是否可预览。
4. 路径、项目包、章节、资料都发布后，才在学习空间显示；非预览内容仍需课程权限。

一个章节可以有多项资料，列表按资料逐项呈现。取消阶段关联不会删除章节或内容。本地现有课程没有自动编入 AI OPC；「内容正在准备中」是未配置状态。视觉验证里的示例课程和产品仅存在于独立测试数据库。

## 后续上线边界

- 新后端模块：server/opc-routes.mjs、server/opc-definition.mjs；server/index.mjs 接入路由。
- 新增表 opc_stage_steps、opc_products，不清空原有数据。
- 上线时需备份数据库，同时发布前端和后端并应用新增表，不能只更新静态首页。本次没有操作生产服务器。
- 新内容接口校验发布状态、角色和权益日期。个人产品只读写当前账号。
- 原有资源存储/下载机制没有改造，不能把内容接口权限检查等同于完成私有文件存储、视频 DRM 或支付。
- 正文目前按安全纯文本显示；后续可增加结构化文档编辑和代码高亮。
