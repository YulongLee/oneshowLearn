# AI 导师：资料检索与对话界面

状态：2026-09-30 经用户明确授权已部署生产。复用后台现有阿里云模型与额度/功能开关，无新模型订阅，无数据库迁移，无生产课程/学习记录改动。

## 回答机制

- 默认「资料问答」：查询时按当前账号权限读取已发布课程/项目课件文字、关联文字资料、文稿和已固定版本的 Prompt；兼容原文档课程。项目阶段验收与免费预览规则保持一致。不读取私人笔记库。
- 文本以约 1000 字、150 字重叠切分，中文双字词/英文词 BM25 排序与标题加权，去重后最多 8 段交给现有聊天模型。限定课程或全部可访问资料。无结果时直接提示不足，不调用模型凑答案。
- 每次请求重新读 CMS，无长期索引缓存；回答返回前重新检查来源、发布/权益、账号状态和登录版本，防止生成期间下架或撤权后仍返回来源。
- 模型须引用本次 `[S编号]`；缺少或伪造编号会转为资料不足提示。引用校验仅验证出处，不等于语义事实核验，界面保留核对提醒。
- 明确的「通用建议」模式保留产品规划与代码帮助，不冒充课程结论。不同模式/课程的历史不会自动混用。产品简介默认不附带，仅显式勾选后发送。
- 无向量 embedding / reranker 配置，因此这一版是关键词检索 RAG，不声称已接入向量库或百炼托管知识库。参考：[阿里云知识库检索说明](https://www.alibabacloud.com/help/en/model-studio/rag-optimization)。视频、图片、PDF/PPT 原件仍不自动解析，需要后台填写课件文字或关联文字稿。
- 有界检索：最多 5000 份文本、500 万字符、12000 个片段；截断时显示部分覆盖提醒。接口独立频控，模型调用仍受后台额度和并发限制。

## 页面

- 保留统一全站侧栏/账号头部，移除导师页机器人海报、宣传侧栏和多列信息卡。
- 独立对话滚动区、底部输入框、简洁欢迎页与四个快捷起点；窄屏两列建议卡，移动端按钮有可访问名称。
- 显示真实等待状态（不是伪流式），支持停止等待、错误后恢复原问题、新对话确认、复制、保存回答及来源到私人笔记。
- 来源可展开原文，并在新标签页打开课程/项目，避免丢失当前对话。对话暂存本页，尚无跨设备会话历史；界面已明示，保存笔记仍走账号版本冲突保护。
- 常见问题右侧常驻，包含课程与资料、项目开发、思路与排错三组共九个问题；问题快捷发送复用真实检索/模型调用，不提供伪造预设答案。前两组资料问答，后一组明确标记通用建议。保留输入草稿、课程范围和已有对话，阻止并发重复请求，失败/停止后可重试。窄屏为顶部折叠面板，支持 Escape 关闭，发问后收起；不改全站导航。
