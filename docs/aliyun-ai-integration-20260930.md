# 阿里云文字 AI 接入（2026-09-30，本地）

## 本次交付

- 使用用户配置中的阿里云百炼兼容接口及 `deepseek-v4-flash` 模型。初始真实连通性调用成功，返回“连接成功”。
- 学习课程与实战项目共享同一个课时 AI：问答、总结、知识点、笔记整理、文本思维导图、复习卡片。上下文来自当前获授权的课时文字、课件文字、已发布 Prompt 与本人笔记，不读取其他人的内容。
- `/tutor` 真实多轮文字对话；可主动选择附带已授权课程简介及本人产品简介。默认不附带，最近对话最多 8 条 / 36,000 字符。对话留在本页内存，回答由用户选择保存为私人笔记。
- 工作台、项目推荐问题转到真实导师输入框，不会自动调用付费模型。未配置时保留明确的不可用状态与原先私人问题笔记功能。
- 无视频理解、图片识别、OCR、PDF/PPT 自动抽取、语音、联网搜索或向量知识库。课件的图片本身不会交给文字模型；维护课程时需要提供课件文字或逐字稿，才能得到有依据的总结。

## 安全和预算

密钥只在服务端环境中使用。没有导入所附文件中的其他项目数据库、支付、短信、存储或其他服务密钥，也没有把原始配置复制到仓库或构建产物。

仅允许阿里云百炼杭州/国际官方 HTTPS 兼容接口；禁止重定向，客户端不能指定密钥、模型、系统提示词或任意服务端上下文。认证、课程/项目权益和阶段权限在发起请求前检查。

默认：单账号每分钟 10 次、滚动 24 小时 30 次；全站滚动 24 小时 300 次。限额使用现有数据库限流表并在重启后保留；发出的失败请求也计入预算。单用户一个在途请求，单进程全站最多 4 个；45 秒超时；输出上限 2,400 tokens，响应上限 1 MB。停止等待不会承诺返还模型用量。若将来横向扩展 API 实例，需要分布式并发限制。

AI 输出为不可信文字，安全 Markdown 渲染，不执行 HTML 或模型代码。错误不返回上游原始响应或认证信息。输出需要人工核对。请求文本及勾选的资料将发给阿里云，界面在发送前明确提示。

## 配置与运行

环境变量说明见 `.env.example` 的 `AI_*`。已有生产配置完全未改动。本地联调使用 `scripts/start-ai-preview.mjs`：必须指定已存在的隔离预览数据库，且 `NODE_ENV=test`；脚本只从用户文件读取三个 `OFFERSTEADY_CHAT_QWEN_*` 字段映射成服务端 `AI_*`，密钥仅驻留进程环境，不输出或写入文件。

后续若获授权上线，需单独安全设置 OneShowLearn 服务端的 `AI_ENABLED / AI_BASE_URL / AI_MODEL / AI_API_KEY`，复核预算，连同 `server/ai-provider.mjs`、`course-ai-service.mjs` 和学习路由发布；不能仅发布前端。`deploy/update-learning.sh` 已将新适配器列入发布依赖，但本次没有执行线上发布。

协议参考：[阿里云百炼 Chat Completions 官方说明](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)。原生 HTTP 请求在顶层设置 `enable_thinking:false`，不向用户输出思考过程。
