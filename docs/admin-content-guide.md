# 管理后台：课程与资料维护

管理入口：`/admin/login`，登录后进入 `/admin`。管理员和内容编辑可使用后台，普通学习者不能进入。使用“切换到用户平台”可检查学习端，无需再次登录。

## 日常维护流程

1. **课程与路径**：维护现有六条路径，或新建课程草稿。填写名称、介绍、封面、地址标识、价格和排序。价格单位为人民币分（29900 分 = 299 元）；更改地址标识会改变课程链接。
2. **课程资料**：选择课程，新增章节，填写目标、顺序与 AI OPC 阶段。选择章节后新增资料。
3. **资料编辑器**：支持实战文档、Prompt、代码、模板、任务、清单、短视频、下载附件。正文支持基础 Markdown 预览（标题、段落、列表、代码块、引用、清单），不支持任意 HTML、嵌入脚本或完整富文本。
4. **附件**：在资料编辑器上传文件或选择附件库中的文件。每个资料条目可附一个资源链接；多个附件可建立多个条目。单文件最大 50 MB，大视频应先压缩或使用合适的视频托管服务。
5. **发布检查**：先发布有正文/附件的资料与章节，再发布课程；所属路径也必须已发布。视频和下载条目必须填写资源地址。草稿/归档的任意父级都会阻止学习端展示。
6. **免费预览**：勾选后，发布链有效时未购买用户也能读取该条目的正文和附件。不要把收费资料误设为免费预览。
7. **调整与下架**：编辑已有记录即可修改；选择“已归档”下架，不永久删除资料及历史学习记录。筛选已归档记录后重新编辑即可恢复。

编辑窗口会提醒未保存修改；旧窗口保存时如遇到其他管理员已修改同一记录，会拒绝覆盖。请先复制自己的修改，关闭编辑、刷新，然后重新编辑。操作记录保存新版 CMS 的操作者、记录名称、时间、动作与状态，不保存完整历史正文，所以不是版本回滚或备份系统。

## 统一资料、实战项目与页面发布

- **统一资料库** `/admin/library`：维护可复用文档、Prompt、代码、模板、任务、清单、视频和附件。原资料只维护一份，修改正文会同步到所有引用它的课程。原资料改为草稿或归档后，学习端所有引用立即不可读取，已保存的学习记录保留。
- **迁入已有资料**：在“课程资料”中编辑条目，先保存修改，再点“纳入统一资料库”。保留原条目 ID、学习记录及原有免费预览设置；不会自动合并内容相似的资料。
- **引用资料**：选择课程章节后点“引用统一资料”。新引用先为草稿，排序、免费预览和发布状态由该章节独立维护；正文在统一资料库编辑。资料、引用、章节、课程及路径都有效发布时才对学习端展示。相同章节不能重复引用同一原资料。
- **实战项目管理** `/admin/projects`：维护独立项目介绍、封面、分类、标签、成果要求、排序与关联课程。至少关联一门已发布课程才能发布。用户端 `/projects` 展示这些项目；详情中的课程沿用各自权限，关联不会赠送课程权限。工作台和学习路线的推荐项目使用同一批记录。归档项目不删除关联课程。
- **页面配置** `/admin/pages`：配置官网首页及登录后工作台的主横幅文案、图片、按钮、推荐内容与行动区文案。不提供任意页面布局编辑，也不替代个人学习数据。推荐内容未选择时展示前四项已发布记录。
- **先预览，再发布**：预览只对管理员可见。保存草稿不会影响用户端；确认发布后，用户刷新页面读取新版本。发布历史可载入编辑器，仍需保存并发布才能恢复。此历史功能仅针对页面配置，不是所有课程正文的版本备份。

新资料库和实战项目库初始为空，不自动复制课程为项目，不创建演示内容。现有课程仍在课程目录中使用；请按实际产品关联课程，并在 AI OPC 管理中完成章节阶段映射。社区、AI 导师、支付等不属于本次内容管理接入范围。

## 附件保护边界

- 新附件保存在 `${UPLOAD_DIR}-private`，不放到公开 `/uploads` 中。读取链接有效期 15 分钟，每次读取还检查资料发布链、账户状态和课程权限。过期后重新打开资料即可获得新链接。
- 对免费预览附件开放匿名读取。管理员/编辑可以在附件库读取尚未发布的附件。
- 外部链接和以前上传到 `/uploads` 的文件仍然是公开资源；不会自动变私密。敏感/收费旧附件需要重新上传并替换引用。删除旧公开文件是另外的迁移操作，本次没有删除。
- 不能阻止已获授权用户将下载后的文件另行分享。

## 本地开发与上线边界

本次开发没有自动部署，也没有修改线上课程。课程、章节、资料的保存由数据库持久化，不是浏览器模拟数据。管理后台保留原有订单、用户、邮件和账号安全入口；在线支付、AI 功能等是否可用仍取决于其自身服务配置，并不因为内容 CMS 完成而自动开通。

未来部署需要同时发布前后端，不能只更新静态文件：

- 备份现有数据库、公开附件和私有附件，保留原环境配置。
- 新增 `cms_audit` 表由服务启动时以增量迁移创建；不执行 seed 或重建数据库。
- 本次还新增统一资料、实战项目及关联、页面草稿与发布历史表，以及 `content_items.library_id`、发布视图和同步保护触发器，均为增量迁移；迁移不自动填充运营内容。
- 服务端发布包必须包括 `cms-routes.mjs`、`materials.mjs`、`platform-content.mjs`、`site-defaults.mjs` 及其依赖。旧的按文件白名单升级脚本不一定涵盖这些模块，不能直接当作本次完整发布方案。
- 根据生产 `UPLOAD_DIR` 创建相邻的 `-private` 目录，归属服务账号且权限 0700。仓库默认路径为 `/var/www/oneshowlearn/uploads-private`；systemd 模板已加入对应 ReadWritePaths，部署自定义路径时应同步调整。
- 若使用仓库安装/升级脚本，先确认脚本创建上述目录再加载新版 unit。不要直接运行会覆盖环境变量或数据库的初始化流程。
- Nginx 不得给私有目录添加静态 alias；上传请求大小需允许 50 MB 文件及 multipart 开销（建议 55m），仅调整 OneShowLearn 站点。
- 重启 OneShowLearn 自身 API 并验证管理权限、草稿隔离、附件下载和其他产品健康情况，不重启或覆盖同机其他产品。
